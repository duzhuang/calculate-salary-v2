# 家教薪资助手 - 设计文档

## 1. 设计理念

本项目是一个面向**移动端**的家教薪资管理工具，设计目标是让老师能够快速记录课程、查看收入、管理学生。采用**移动端优先**的设计策略，以简洁、高效、专业为核心原则。

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **移动优先** | 所有交互首先为手机设计，确保单手操作友好 |
| **信息密度适中** | 在有限屏幕空间内展示关键信息，避免信息过载 |
| **操作效率** | 减少输入步骤，多用选择、自动填充 |
| **视觉清晰** | 数据层次分明，收入数据一目了然 |
| **反馈及时** | 每个操作都有明确的视觉/触觉反馈 |

## 2. 设计系统

### 2.1 色彩系统

基于 UI/UX Pro Max 推荐的 Productivity Tool 色彩方案，采用 Teal（青绿色）为主色调，Orange（橙色）为强调色。

#### 语义色彩 Token

| Token | 浅色模式 | 深色模式 | 用途 |
|-------|---------|---------|------|
| `--color-primary` | `#0D9488` | `#14B8A6` | 主色调（导航、按钮、链接） |
| `--color-on-primary` | `#FFFFFF` | `#FFFFFF` | 主色调上的文字 |
| `--color-secondary` | `#14B8A6` | `#2DD4BF` | 次要操作 |
| `--color-accent` | `#EA580C` | `#FB923C` | 强调色（CTA、重要数字） |
| `--color-background` | `#F0FDFA` | `#0F172A` | 页面背景 |
| `--color-foreground` | `#134E4A` | `#F0FDFA` | 主要文字 |
| `--color-card` | `#FFFFFF` | `#1E293B` | 卡片背景 |
| `--color-card-foreground` | `#134E4A` | `#E2E8F0` | 卡片内文字 |
| `--color-muted` | `#E8F1F4` | `#334155` | 次要背景 |
| `--color-muted-foreground` | `#64748B` | `#94A3B8` | 次要文字 |
| `--color-border` | `#99F6E4` | `#334155` | 边框 |
| `--color-destructive` | `#DC2626` | `#EF4444` | 危险操作（删除） |
| `--color-success` | `#16A34A` | `#22C55E` | 成功状态 |
| `--color-ring` | `#0D9488` | `#14B8A6` | 焦点环 |

#### 色彩使用规则

- **收入数字**：使用 `--color-accent`（橙色）突出显示
- **课时数字**：使用 `--color-primary`（青绿色）
- **删除按钮**：使用 `--color-destructive`（红色）
- **背景层次**：页面背景 → 卡片背景 → 卡片内元素，形成清晰层次

### 2.2 字体系统

| 用途 | 字体 | 字重 | 大小 |
|------|------|------|------|
| 页面标题 | Nunito | 700-800 | 20-24px |
| 卡片标题 | Nunito | 700 | 18px |
| 正文 | DM Sans | 400 | 16px |
| 标签 | DM Sans | 500 | 14px |
| 辅助文字 | DM Sans | 400 | 12px |

**字体导入**
```css
@import url('https://fonts.googleapis.com/css2?family=DM+Sans:ital,wght@0,400;0,500;0,700;1,400&family=Nunito:wght@700;800&display=swap');
```

- 金额使用等宽数字（tabular-nums），避免宽度跳动
- 大金额（>10000）显示为 "X.X 万" 格式

## 3. 页面结构

```
┌─────────────────────────────┐
│         Status Bar          │  ← 系统状态栏
├─────────────────────────────┤
│         Header              │  ← 页面标题（固定顶部）
│         (48px)              │
├─────────────────────────────┤
│                             │
│         Content             │  ← 可滚动内容区域
│         (scrollable)        │
│                             │
│                             │
├─────────────────────────────┤
│       Bottom Nav            │  ← 底部导航栏（固定底部）
│       (60px + safe area)    │
└─────────────────────────────┘
```

### 3.2 底部导航栏

底部导航栏是应用的核心导航，最多 5 个 Tab：

```
┌─────────────────────────────────────────────┐
│                                             │
│   📝        📊        ➕        👥        ⚙️  │
│   记录      总览      记账      学生      更多  │
│                                             │
└─────────────────────────────────────────────┘
```

| Tab | 图标 | 路由 | 说明 |
|-----|------|------|------|
| 记录 | `Calendar` | `/` | 首页，显示当日/当月记录 |
| 总览 | `BarChart3` | `/overview` | 年度/月度/日度汇总 |
| 记账 | `PlusCircle` (大) | `/record` | 快速添加新记录 |
| 学生 | `Users` | `/students` | 学生管理 |
| 更多 | `MoreHorizontal` | `/more` | 导入导出、设置 |

**设计规范**
- 当前选中项：`--color-primary` 图标 + 文字
- 未选中项：`--color-muted-foreground` 图标 + 文字
- "记账" Tab 使用强调色圆形按钮，突出显示
- 底部导航固定，内容区域需添加底部 padding 避免被遮挡
- 支持 iOS safe area（`env(safe-area-inset-bottom)`）

## 5. 组件规范

### 5.1 按钮 (Button)

| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | `bg-primary text-white rounded-md` | 主要操作（保存、提交） |
| Secondary | `bg-muted text-foreground rounded-md` | 次要操作（取消） |
| Destructive | `bg-destructive text-white rounded-md` | 危险操作（删除） |
| Ghost | `bg-transparent text-foreground` | 低优先级操作 |
| Icon | `w-11 h-11 rounded-full` | 图标按钮 |

**尺寸规范**
- 最小触摸区域：44×44px（iOS HIG）
- 按钮内边距：`px-4 py-3`
- 按钮间距：至少 8px

**状态**
- Default → Hover (opacity 90%) → Active (scale 0.98) → Disabled (opacity 50%)

### 5.2 输入框 (Input)

```
┌─────────────────────────────────┐
│ 标签 (14px, medium, muted-fg)   │
│ ┌─────────────────────────────┐ │
│ │                             │ │
│ │  输入内容 (16px, foreground) │ │  ← 高度 ≥ 44px
│ │                             │ │
│ └─────────────────────────────┘ │
│ 帮助文字 / 错误文字 (12px)      │
└─────────────────────────────────┘
```

**规范**
- 高度：≥ 44px（触摸友好）
- 圆角：10px
- 边框：`border border-border`
- 焦点状态：`ring-2 ring-primary`
- 错误状态：`border-destructive`
- 使用 `inputmode` 属性触发正确的手机键盘

### 5.3 卡片 (Card)

```
┌─────────────────────────────────┐
│                                 │
│  卡片内容                        │  ← padding: 16px
│                                 │
└─────────────────────────────────┘
```

**规范**
- 背景：`bg-card`
- 圆角：10px
- 阴影：`shadow-sm`
- 内边距：16px
- 外边距：卡片间距 12px

## 6. 动画与过渡

### 6.1 动画规范

| 场景 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 页面切换 | 200-300ms | ease-out | 水平滑动 |
| 卡片展开 | 200ms | ease-in-out | 高度变化 |
| 按钮点击 | 100ms | ease-out | scale(0.98) |
| Toast 显示 | 300ms | spring | 从底部滑入 |
| Toast 消失 | 200ms | ease-in | 向上淡出 |
| 列表项进入 | 150ms/项 | ease-out | 交错动画（30ms 间隔） |
| 加载骨架 | 1.5s | linear | shimmer 循环 |

### 6.2 手势交互

| 手势 | 操作 | 说明 |
|------|------|------|
| 左滑记录卡片 | 显示删除/编辑 | 类似邮件 App |
| 下拉 | 刷新数据 | Pull-to-Refresh |
| 点击 | 选择/展开 | 主要交互方式 |

### 6.3 无障碍

- 尊重 `prefers-reduced-motion`，禁用非必要动画
- 所有交互元素支持键盘导航
- 焦点环使用 `ring-2 ring-primary`

## 7. 响应式策略

### 7.1 断点

| 断点 | 宽度 | 设备 |
|------|------|------|
| 默认 | < 640px | 手机（主要目标） |
| `sm` | ≥ 640px | 大手机/小平板 |
| `md` | ≥ 768px | 平板 |
| `lg` | ≥ 1024px | 桌面 |

### 7.2 布局适配

**手机（< 640px）**
- 单列布局
- 底部 Tab 导航
- 卡片全宽显示
- 表单单列排列

**平板/桌面（≥ 768px）**
- 最大宽度 480px 居中显示（保持手机 App 体验）
- 或切换为侧边栏导航 + 双列布局

## 10. Toast 消息

| 类型 | 颜色 | 图标 | 场景 |
|------|------|------|------|
| 成功 | `--color-success` | `Check` | 保存/删除成功 |
| 错误 | `--color-destructive` | `XCircle` | 操作失败 |
| 信息 | `--color-primary` | `Info` | 提示信息 |

**规范**
- 位置：屏幕顶部（Header 下方）
- 自动消失：3 秒
- 可手动关闭
- 不抢夺焦点（`aria-live="polite"`）

## 11. 深色模式

### 11.1 切换方式

在"更多"页面提供开关，或支持跟随系统设置。

### 11.2 深色模式色彩

- 使用语义色彩 Token 自动适配
- 不简单反转颜色，而是使用低饱和度、低亮度的调色板
- 确保文字对比度 ≥ 4.5:1（WCAG AA）
- 卡片使用 `#1E293B` 背景，与页面背景 `#0F172A` 形成层次
